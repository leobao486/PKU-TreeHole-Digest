# PKU Treehole Digest

一个面向个人使用的 Windows 桌面工具：按时间范围读取北大树洞帖子，调用 DeepSeek API 进行分类、相关度评分和摘要，最后生成本地 HTML 报告。

## 隐私说明

- 账号、密码和 DeepSeek API Key 通过系统凭据管理器保存，不写入项目文件。
- 树洞会话与运行状态保存在 `%LOCALAPPDATA%\PKUTreeholeDigest`，不在仓库目录中。
- `个人画像.yaml`、报告、原始抓取和本地配置均已加入 `.gitignore`。
- 帖子正文和评论会发送给配置的 DeepSeek API。使用前请自行评估学校规则、平台条款和数据处理风险。
- 不要把报告、原始树洞内容、会话文件、截图或真实个人画像提交到公开仓库。

## 安装与运行

1. 安装 Python 3.11 或更高版本。
2. 双击 `安装依赖.cmd`。它会创建本地虚拟环境，并在首次安装时复制一份被 Git 忽略的 `个人画像.yaml`。
3. 双击 `运行树洞日报.cmd`。
4. 在窗口中填写登录信息、DeepSeek API Key，并根据自己的需求修改个人画像。

## 默认筛选规则

- 首次生成扫描此前 24 小时；以后根据报告目录中最新的时间戳继续扫描。
- 高热度强制入选条件：评论数不小于 20，或收藏数不小于 20。
- 常规精选数量以扫描总数的约 10% 为中心，根据相关度分布自适应调整。
- DeepSeek 生成分类、相关度、每帖摘要和整体概览，不生成紧急度、入选原因或建议行动。
- HTML 报告包含左侧目录、复制洞号按钮，以及可滚动的原帖与评论弹窗。
